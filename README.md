# CineFind 🍿

Find where films from your Letterboxd lists, watchlist, or diary are currently streaming in India.

### Features
- 🔍 **Instant Search & Import**: Scrape Letterboxd watchlists, public lists, and diary pages directly.
- 📺 **India OTT Availability**: Enriched via TMDB & JustWatch for major OTT platforms (Netflix, Prime Video, JioHotstar, Sony LIV, MUBI, etc.).
- ⚡ **Optimized Stack**: Built with Next.js (App Router), Tailwind CSS, Cheerio, Turso SQLite, and Upstash Redis.
